# Сайт Kurme

Структура: `index.html` в корне репозитория и папка `data` со всем остальным (фото, цены, прайс-лист, редактор).

## Загрузка на GitHub
1. Откройте репозиторий `kurme` → **Add file → Upload files**.
2. Перетащите в окно файл `index.html` и ПАПКУ `data` целиком (саму папку, не файлы из нее).
3. Нажмите **Commit changes**.
4. **Settings → Pages**: Deploy from a branch, ветка `main`, папка `/(root)`.
5. Сайт: https://ВАШ-ЛОГИН.github.io/kurme/ , прайс-лист: .../data/price.html

## Как менять цены и телефон
1. Откройте `data/editor.html` на своем компьютере (двойной клик), нажмите «Открыть products.json» и выберите `data/products.json`.
2. Впишите цены, телефон WhatsApp (цифры с кодом страны, например 77011234567) и т.д.
3. Нажмите «Скачать products.json» и загрузите его на GitHub в папку `data` (откройте папку data → Add file → Upload files) вместо старого.

## Фото
Фото лежат в папке `data` и называются `pp6-1.jpg` (полипропилен 6 мм, 1-е фото), `hemp6-1.jpg` (пенька 6 мм). Новое фото загрузите в папку `data` и впишите его имя в поле «Фото» в редакторе.
